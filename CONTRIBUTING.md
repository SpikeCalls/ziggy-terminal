# Contributing

Ziggy is still learning, and so is this repo.

1. Fork it, make a branch.
2. `cd studio && npm install && npm run serve`, open `http://localhost:8765/?t=9` to jump to any second.
3. Everything on screen is a function of time in `window.renderAt(t)` — keep it that way so frames stay deterministic.
4. Run `npm run preview` and attach the stills to your PR.

Good first ideas: new tickers and trade stories, a horizontal 16:9 cut, a second fly, more brain regions lighting up.
